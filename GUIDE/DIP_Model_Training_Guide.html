How to Train the Models: CNN, GNN, and Hybrid Architectures

This technical guide explains how to formulate the dataset, loss functions, and forward/backward training pipelines for CNN, GNN, and Hybrid (CNN+GNN) approaches using clean mathematical notation alongside simple, intuitive explanations for beginners.

1. The Three Core Pillars of Model Training

Regardless of whether you use a CNN, GNN, or Hybrid model, every training process relies on three fundamental pillars:

  1. Dataset & Training Pair Generation: Defining input-target pairs $(\text{Input } X \rightarrow \text{Ground Truth Target } Y)$.
  2. Loss Function & Optimization: Calculating mathematical error between prediction $\hat{Y}$ and true target $Y$, and updating model weights through gradient backpropagation ($\nabla_\theta \mathcal{L}$).
  3. Architecture-Specific Data Flow: Managing how tensors (images or graphs) flow through layers during the forward pass.
💡 Plain-English Analogy (Studying with Flashcards):

Think of training an AI model like a student preparing for an exam with flashcards:

  • The Question (Input $X$): The damaged or compressed picture tile.
  • The Student's Guess ($\hat{Y}$): What the AI predicts the missing details should look like.
  • The Answer Key (Target $Y$): The untouched original picture.
  • The Penalty / Loss ($\mathcal{L}$): How far off the guess was. The student's brain (model weights $\theta$) adjusts to make fewer mistakes next time.

2. Step 0: The Common Foundation (Data Generation)

A major advantage of this project is that no manual human labeling is needed. It is a self-supervised task constructed directly from clean grayscale image datasets (e.g., Set5, BSDS500, DIV2K).

Figure 1: Self-Supervised Training Pair Extraction Pipeline
Formal Mathematical Definitions:
  • Input ($X$): An $8 \times 8$ block $C_{\text{trunc}}(u, v)$ where high-frequency coordinates are zeroed out: $$C_{\text{trunc}}(u, v) = \begin{cases} C_{\text{orig}}(u, v), & (u, v) \in \Omega_{\text{low}} \\ 0, & (u, v) \in \Omega_{\text{high}} \end{cases}$$
  • Target ($Y$): The true high-frequency coefficients $\{C_{\text{orig}}(u, v) \mid (u, v) \in \Omega_{\text{high}}\}$, or the original spatial pixel patch $I_{\text{clean}}$.
💡 Plain-English Summary:

In simple words: We take an ordinary clear photo, cut it into $8 \times 8$ squares, and convert it to frequencies. We keep the true numbers as our Answer Key ($Y$), then erase the fine-detail numbers to 0 to make our Question ($X$). That gives us millions of free test questions with answers!

3. Approach 1: Training the Pure CNN Model (like CARD)

In a standard CNN architecture, all data stays in 4D grid tensors formatted as [Batch_Size, Channels, Height, Width].

1. Data Flow in CNN Training

  • Input: Degraded 2D image patches $X \in \mathbb{R}^{B \times 1 \times H \times W}$ (e.g., $64 \times 64$ patches with blurred edges and blocking lines).
  • Forward Pass: Passes through convolutional feature-extraction and wide-activation residual layers.
  • Output: Restored spatial patch $\hat{I} \in \mathbb{R}^{B \times 1 \times H \times W}$.
Figure 2: Pure CNN Training & Gradient Optimization Loop

2. Loss Function & Optimization

$$\mathcal{L}_{\text{CNN}} = \frac{1}{N} \sum_{p=1}^{N} \left| \hat{I}(p) - I_{\text{clean}}(p) \right|$$
Mean Absolute Error ($L_1$ Loss) over all $N$ pixel coordinates $p$.

Optimizer: Adam with learning rate $\alpha = 10^{-4}$, $\beta_1 = 0.9$, and $\beta_2 = 0.999$. Minimizing $L_1$ loss forces the convolutional kernels to eliminate grid seams and sharpen edges.

💡 Plain-English Meaning of Equation:

The equation simply means: Compare the AI's cleaned picture with the real original picture pixel by pixel. Add up how far off the colors were, and take the average. The optimizer adjusts the CNN filters to make this error as close to zero as possible.

3. How to Actually Train the CNN

Practical CNN Training Execution:

  1. Data Loader: Extract $64 \times 64$ patches from images. Generate $X$ by applying block DCT, zeroing out high frequencies, and inverting back. $Y$ is the original $64 \times 64$ patch.
  2. Batch Loop: Pass batches of $X$ into output = cnn_model(X).
  3. Compute Error: loss = torch.mean(torch.abs(output - Y)).
  4. Backpropagation: Call loss.backward() and optimizer.step().

4. Approach 2: Training the Pure GNN Model (The Scholar's Approach)

In this model, images are represented as graphs of frequency nodes rather than 2D pixel grids.

💡 Plain-English Concept (The Musical Harmonics Analogy):

A GNN doesn't look at pictures like eyes do; it looks at relationships. Think of a guitar: when you pluck a low note, it naturally vibrates and creates higher harmonic sounds. Even if a mute cuts off the high sound, a trained musician who hears the low note can deduce what the high notes should be! The GNN learns the exact same harmonic relationships between low and high frequencies.

1. How the Graph is Prepared for Training

For every $8 \times 8$ DCT block, a graph $\mathcal{G} = (\mathcal{V}, \mathcal{E})$ is constructed:

  • Node Feature Matrix ($V \in \mathbb{R}^{64 \times D}$): Each node represents one frequency index $i \in \{0, 1, \dots, 63\}$.
    • Nodes $i \in \Omega_{\text{low}}$: Contain known low-frequency DCT values $C_i$.
    • Nodes $i \in \Omega_{\text{high}}$: Initialized with value $0.0$.
    • Positional Encoding: Normalized 2D coordinates $(u_i / 8, v_i / 8)$ are concatenated to node features so the network knows each node's exact frequency location.
  • Edge Set ($\mathcal{E}$): Predefined harmonic adjacency list connecting lower frequencies $(u, v)$ to their harmonics $(2u, 2v)$, $(u+1, v)$, and $(u, v+1)$.
  • Ground Truth Target ($Y$): True scalar values $C_i^{\text{true}}$ for all $i \in \Omega_{\text{high}}$.

2. Loss Function & Reconstruction

The loss function is calculated strictly over the missing high-frequency nodes ($\Omega_{\text{high}}$):

$$\mathcal{L}_{\text{GNN}} = \frac{1}{|\Omega_{\text{high}}|} \sum_{i \in \Omega_{\text{high}}} \left( \hat{C}_i - C_i^{\text{true}} \right)^2$$
Node-Level Mean Squared Error ($L_2$ Loss) where $|\Omega_{\text{high}}|$ is the number of missing frequencies.
💡 Plain-English Meaning of Equation:

Why don't we grade all 64 nodes? Because the low frequencies were already known! We only test the model on the missing numbers ($\Omega_{\text{high}}$). Take each guessed number, subtract the true number from our answer key, square it, and average them together.

During inference, the predicted high-frequency values $\hat{C}_i$ are assembled with the known low-frequency values $C_{\text{low}}$, and 2D-IDCT transforms the completed matrix back into the restored spatial domain.

3. How to Actually Train the GNN (Step-by-Step)

Detailed GNN Training Walkthrough:

  1. PyTorch Geometric Graph Dataset: Convert each $8 \times 8$ block into a Data(x=node_features, edge_index=edges, y=ground_truth_high_freqs) object.
    • node_features is a $64 \times 3$ tensor: `[frequency_value, u_coord, v_coord]`.
    • edge_index is a $2 \times E$ tensor defining the harmonic pairs.
  2. Forward Pass: The GNN model (2 to 3 layers of GCNConv or GATConv) propagates messages between connected nodes, updating their hidden states.
  3. Linear Regression Head: A final nn.Linear(hidden_dim, 1) maps the hidden states of missing nodes into predicted scalar DCT amplitudes $\hat{C}_i$.
  4. Loss Calculation: Compute MSE loss strictly over indices $i \in \Omega_{\text{high}}$ (ignoring known low frequencies).
  5. Backward Pass: loss.backward() updates the GNN edge-weight and convolution parameters.

Executable PyTorch Geometric Training Loop:

# Training Loop for Pure GNN (PyTorch Geometric)
import torch
import torch.nn as nn
from torch_geometric.loader import DataLoader

optimizer = torch.optim.Adam(gnn_model.parameters(), lr=1e-3)
criterion = nn.MSELoss()

for epoch in range(num_epochs):
    for batch in dataloader:
        optimizer.zero_grad()
        
        # 1. Forward Pass: GNN predicts values for all nodes in the batch
        pred_nodes = gnn_model(batch.x, batch.edge_index)
        
        # 2. Compute loss strictly on missing high-frequency nodes (missing_mask)
        loss = criterion(pred_nodes[batch.missing_mask], batch.y_true[batch.missing_mask])
        
        # 3. Backpropagate error and step optimizer
        loss.backward()
        optimizer.step()
        
    print(f"Epoch {epoch}: Node MSE Loss = {loss.item():.4f}")

5. Approach 3: Training the Hybrid Model (CNN + GNN)

The Hybrid architecture is trained end-to-end, where the CNN feature extractor and GNN message-passing network are optimized simultaneously in a unified computational graph.

💡 Plain-English Concept (Eyes + Brain Working Together):
  • The CNN is the "Eyes": It looks at real 2D pixel pictures, spotting local edges, textures, and gradients.
  • The GNN is the "Brain": It receives what the eyes saw, connects the mathematical harmonic lines, and smooths out the seams between neighboring blocks.

1. End-to-End Forward Pass

  1. The degraded image patch passes through a Shallow CNN Feature Extractor $f_{\text{CNN}}$ to produce local edge and gradient feature maps.
  2. A reshape/adapter layer maps local CNN feature vectors into graph node states $h_i^{(0)}$.
  3. The GNN Layers (GAT / GCN) propagate messages across harmonic frequency edges and inter-block boundary seams.
  4. A linear head outputs the predicted high-frequency DCT matrix $\hat{C}$.
  5. A Differentiable 2D-IDCT Layer synthesizes the final restored image: $\hat{I} = \text{IDCT}(\hat{C})$.

2. The Dual-Domain Loss Function

The hybrid architecture is supervised in both the spatial pixel domain and the frequency domain at the same time:

$$\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{pixel}} + \lambda \cdot \mathcal{L}_{\text{frequency}}$$
Combined Dual-Domain Objective Function where $\lambda$ is a balancing coefficient (typically $\lambda = 0.1$).

Expanding the two components:

$$\mathcal{L}_{\text{pixel}} = \frac{1}{N} \sum_{p=1}^{N} \left| \hat{I}(p) - I_{\text{clean}}(p) \right|, \quad \mathcal{L}_{\text{frequency}} = \frac{1}{|\Omega_{\text{high}}|} \sum_{i \in \Omega_{\text{high}}} \left( \hat{C}_i - C_i^{\text{true}} \right)^2$$
$\mathcal{L}_{\text{pixel}}$ drives seamless boundary reconstruction, while $\mathcal{L}_{\text{frequency}}$ enforces mathematical harmonic decay.
💡 Plain-English Meaning of Dual-Domain Loss:

This gives the hybrid model a two-part test:

  1. Test 1 ($\mathcal{L}_{\text{pixel}}$): Does the reconstructed photo look sharp, realistic, and free of blocky grid seams to human eyes?
  2. Test 2 ($\mathcal{L}_{\text{frequency}}$): Did it obey the mathematical rules of frequency harmonics?

Because the model has to pass both tests simultaneously, it produces much better results than any single model alone!

3. How to Actually Train the Hybrid Model (Step-by-Step)

Detailed Hybrid Training Walkthrough:

  1. Unified Forward Pass:
    • The input image patch $X$ passes through the CNN, generating local feature maps $F \in \mathbb{R}^{B \times C \times H' \times W'}$.
    • A graph projection layer transforms each spatial block's feature vector into node states in a graph.
    • The GNN performs message passing over harmonic links and boundary seam links.
    • The network outputs predicted DCT coefficients $\hat{C}$.
    • A differentiable 2D-IDCT layer in PyTorch converts $\hat{C}$ into spatial image $\hat{I}$.
  2. Dual-Domain Loss Computation:
    • Calculate $\mathcal{L}_{\text{pixel}} = \text{mean}(|\hat{I} - I_{\text{clean}}|)$ to enforce clean visual borders.
    • Calculate $\mathcal{L}_{\text{frequency}} = \text{mean}((\hat{C} - C_{\text{true}})^2)$ on missing frequencies.
    • Calculate combined loss: $\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{pixel}} + 0.1 \times \mathcal{L}_{\text{frequency}}$.
  3. Joint Gradient Flow: When calling total_loss.backward(), gradients flow through the differentiable IDCT, through the GNN, through the graph adapter, and into the CNN feature extractor simultaneously.

Executable PyTorch Hybrid Training Loop:

# Joint Training Loop for Hybrid Model (CNN + GNN)
optimizer = torch.optim.Adam(hybrid_model.parameters(), lr=1e-4)

for epoch in range(num_epochs):
    for batch_images, batch_true_freqs, batch_clean_images in dataloader:
        optimizer.zero_grad()
        
        # 1. Forward Pass: CNN extracts features -> GNN reasons -> IDCT rebuilds image
        pred_image, pred_freqs = hybrid_model(batch_images)
        
        # 2. Pixel Domain Error (Forces edge sharpness and seam removal)
        loss_pixel = torch.mean(torch.abs(pred_image - batch_clean_images))
        
        # 3. Frequency Domain Error (Forces harmonic accuracy)
        loss_freq = torch.mean((pred_freqs - batch_true_freqs) ** 2)
        
        # 4. Total Dual-Domain Objective
        total_loss = loss_pixel + 0.1 * loss_freq
        
        # 5. Backpropagate through BOTH architectures at the same time
        total_loss.backward()
        optimizer.step()
        
    print(f"Epoch {epoch}: Total Loss = {total_loss.item():.4f}")

7. Where to Start: Immediate Coding Steps for the Team

Recommended Starting Path (Phase 1 Assignment Submission):
  1. Step 1: Write the Preprocessing Script: Load standard benchmark images (Lena, Cameraman, or BSDS), chop into $8 \times 8$ blocks, apply SciPy/PyTorch dctn(), and zero-out frequencies beyond cutoff radius $R$.
  2. Step 2: Measure Classical Baseline: Run idctn() on the zero-padded blocks and record the baseline PSNR (usually around 24–27 dB).
  3. Step 3: Build the PyTorch Geometric Dataset: Create graph data objects where nodes represent the 64 coefficients and edges link $(u, v)$ to $(2u, 2v)$.
  4. Step 4: Train a 3-Layer GCN/GAT: Train the GNN on missing nodes using the node-level MSE loss.
  5. Step 5: Compare: Run IDCT on the predicted coefficients and measure the PSNR gain over the baseline (target: $+1.5\text{ to }+3.0\text{ dB}$ gain!).
