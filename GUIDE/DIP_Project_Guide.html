Digital Image Processing • Project Guide & Technical Reference

High-Frequency DCT Coefficient Prediction for Enhanced Image Reconstruction

This technical summary explains our DIP assignment project, the physics and mathematics of Discrete Cosine Transform (DCT) degradation, and how CNN, GNN, and Hybrid (CNN+GNN) architectures solve this problem.

1. Project Overview

In digital image processing, lossy compression (such as JPEG) splits images into 8×8 blocks, converts them to the frequency domain using the Discrete Cosine Transform (DCT), and removes high-frequency coefficients to save storage.

Project Goal: Instead of accepting blurry, blocky images from standard Inverse DCT (IDCT) reconstruction, we train a machine learning model to predict the missing high-frequency coefficients from the preserved low-frequency coefficients, restoring clean edges and fine textures.

2. The Core Problem: Why Do Images Degrade?

What Happens in an 8×8 DCT Block?

When an 8×8 block of pixels is converted into DCT space, its 64 coefficients represent spatial patterns rather than individual pixels:

  • Top-Left (DC Coefficient): Represents the average brightness/color of the entire block. Holds the vast majority of image energy.
  • Middle Frequencies (Low AC): Represents smooth gradients and broad geometric shapes.
  • Bottom-Right (High AC): Represents fine lines, sharp object edges, and microscopic textures (hair, fabric, grain).
Figure 1: 8×8 DCT Frequency Layout & Truncation Cutoff

Why Do Artifacts Happen?

  1. Information Loss: When high frequencies are zeroed out, sharp edges lose the exact mathematical waves needed to cancel overshoot, creating ripples (ringing).
  2. Independent Block Processing: Each 8×8 block is transformed in total isolation. When pixel values at the borders are modified without checking neighbor blocks, the boundary edges no longer align, producing a visible grid pattern across the picture.

4. Approach A: The Pure CNN Model

A Convolutional Neural Network (such as CARD) treats the image or DCT patch as a regular 2D pixel array, running 2D filters over sliding windows.

What CNN is Good At:

  • Local Spatial Pattern Recognition: Highly optimized for detecting local gradients, corners, edges, and line orientations in 2D image coordinates.
  • Hardware Acceleration: Modern GPUs execute 2D convolutions using Tensor Cores with exceptional speed.
  • Translation Invariance: An edge looks like an edge regardless of where it appears in the frame.

Where CNN Falls Short:

  • Ignores Harmonic Relationships: High-frequency DCT coefficients follow mathematical frequency harmonic decay. A CNN treats the 8×8 frequency matrix as ordinary pixels, completely oblivious to harmonic mathematics.
  • Rigid, Fixed Receptive Fields: A CNN only inspects immediate spatial neighbors (e.g., 3×3 or 5×5). It cannot easily connect two distant blocks that share the identical texture pattern without dozens of layers.

5. Approach B: The Pure GNN Model

A Graph Neural Network models elements as nodes connected by flexible edges, exchanging information through message passing.

How the Graph is Constructed:

  • Nodes: The frequency positions inside the 8×8 block (e.g., node 0 = DC, node 1 = AC1, up to node 63).
  • Harmonic Edges: Edges link low frequencies directly to their higher-order harmonic frequencies, allowing the network to explicitly learn: "Given low frequency amplitude X, high-frequency harmonic Y should be Z."
  • Inter-Block Boundary Edges: Connecting neighboring blocks across borders to explicitly exchange boundary values.
Figure 3: Graph Formulation of DCT Frequencies & Block Boundaries

What GNN is Good At:

  • Relational Reasoning: Directly maps how energy transfers across frequency octaves.
  • Block Boundary Healing: Explicitly passes messages across block borders to eliminate blocking artifacts.
  • Long-Range Similarities: Can connect non-adjacent blocks across the image that share similar texture profiles.

Where GNN Falls Short:

  • Poor at Raw Local Spatial Filtering: GNNs do not have native spatial convolution kernels to detect continuous 2D textures or edges directly from raw pixel arrays.
  • Over-Smoothing Risk: When GNNs go beyond 3-4 layers, node representations can blend together and become identical, losing sharpness.

6. Approach C: The Hybrid (CNN + GNN)

The Hybrid model couples both worlds: the CNN acts as the "Sensory Eyes" and the GNN acts as the "Relational Brain."

Why the Hybrid Model is the Best Solution

  1. Clear Division of Labor:
    • CNN's Role: Scans local 2D image blocks and extracts high-quality edge, gradient, and texture features.
    • GNN's Role: Takes those rich feature vectors, models frequency harmonic relationships, and predicts missing high-frequency coefficients while smoothing seams across neighboring blocks.
  2. Resolves Weaknesses of Both: The CNN solves the GNN's inability to extract rich 2D spatial features, while the GNN solves the CNN's inability to model non-local relationships and harmonic structures.

8. Roadmap for the Team

To ensure we finish on time and produce high marks for the assignment while opening the door for an academic research paper, we will proceed in two distinct phases:

Phase 1: Course Assignment (Pure GNN Pipeline)
  1. Implement 8×8 block 2D-DCT and high-frequency coefficient truncation in Python.
  2. Implement standard zero-padded 2D-IDCT baseline and compute baseline PSNR/SSIM.
  3. Construct the frequency graph using PyTorch Geometric (PyG).
  4. Train a GCN/GAT model to predict missing coefficients and measure PSNR/SSIM gain over baseline.
  5. Submit report and demonstrate project completion.
Phase 2: Research Paper Extension (CNN + GNN Hybrid)
  1. Attach a shallow CNN encoder before graph construction to extract spatial image features.
  2. Connect cross-block spatial edges and harmonic frequency edges simultaneously.
  3. Benchmark against baseline IDCT, pure CNN, and pure GNN (ablation study).
  4. Write manuscript detailing novelty and results for conference submission.
